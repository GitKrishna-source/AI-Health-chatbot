# 🩺 DoctorAI – AI Health Chatbot

DoctorAI is a web-based AI health chatbot that provides **general health-related information** such as headaches, sore throat, and other common conditions using **Google Gemini AI**.

This project is built for **learning and demonstration purposes**, focusing on API integration, backend–frontend communication, and environment-based configuration.

---

## 🚀 Features
- AI-powered responses using **Google Gemini**
- Simple and clean chat-based UI
- Node.js + Express backend
- Secure API key handling using `.env`
- Beginner-friendly project structure

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **AI API:** Google Gemini (Generative Language API)
